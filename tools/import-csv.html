Card CSV importer

Converts a design spreadsheet into the card literals used by src/data/cards.js. It fills in everything mechanical — id, name, stage, type, HP, retreat, move names, costs and damage — and then lists the moves and abilities whose rules text implies behaviour, because those need an effect id that you implement in the registries. Nothing is guessed silently.

5. Then

  1. Add the set to src/data/sets.js with the exact filename prefix.
  2. Drop the card images into cards/, named to match each id.
  3. Implement each listed effect in src/core/effects.js, ability in src/core/abilities.js, item in src/core/items.js.
  4. Open test.html. The validator will name anything still missing; the fuzzer will play thousands of games with the new cards.
